# client-server
Try socket programming

┌─────────────────────────────────────────────────────────────┐
│ 1. socket()                                                 │
│    → создаём TCP-сокет, получаем файловый дескриптор        │
│      (server_fd = 3)                                        │
└────────┬────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. signal(SIGPIPE, SIG_IGN)                                 │
│    → игнорируем SIGPIPE, чтобы сервер не падал при          │
│      записи в разорванное соединение                        │
└────────┬────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. setsockopt()                                             │
│    → разрешаем переиспользовать адрес и порт                │
│      (SO_REUSEADDR | SO_REUSEPORT)                          │
│      позволяет сразу перезапустить сервер после закрытия    │
└────────┬────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. bind()                                                   │
│    → привязываем сокет к адресу INADDR_ANY (0.0.0.0)        │
│      и порту 2255                                           │
└────────┬────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│ 5. listen()                                                 │
│    → переводим сокет в режим ожидания, размер очереди = 8   │
└────────┬────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│ 6. for (;;)                                           │
│      accept() ← БЛОКИРУЕТСЯ                                 │
│      → ждём подключения клиента                             │
│      → при подключении создаётся НОВЫЙ сокет                │
│        (new_socket = 4)                                     │
└────────┬────────────────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────────────────────────┐
│ 7. while (read_line() == 0) {                              │
│      → читаем команду от клиента построчно                 │
│      → поддерживается несколько команд в одном соединении  │
│                                                            │
│      if (line == "etc"):                                   │
│        - открываем /etc                                    │
│        - ищем файлы *.conf                                 │
│        - проверяем, что это обычные файлы (is_regular_file)│
│        - формируем ответ: "server5239,file1.conf,file2..." │
│      else if (line == "dev"):                              │
│        - открываем /dev                                    │
│        - ищем поддиректории (is_directory)                 │
│        - формируем ответ: "dir1,dir2,dir3..."              │
│      else:                                                 │
│        - ответ: "Unknown command\n"                        │
│                                                            │
│      → добавляем \n в конец ответа                         │
│      → send_all() отправляем ответ клиенту                 │
│    }                                                       │
└────────┬───────────────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────────────────────────┐
│ 8. close(new_socket)                                       │
│    → закрываем соединение с текущим клиентом               │
│    → освобождаем дескриптор 4                              │
│    → возвращаемся к accept() для следующего клиента        │
└────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────┐
│ КАК ЗАПУСТИТЬ (каталог client-server_c):                    │
├─────────────────────────────────────────────────────────────┤
│ 1. Сборка:                                                  │
│      make                                                   │
│                                                             │
│ 2. Терминал A — только сервер (порт 2255):                  │
│      ./server                                               │
│    Окно «зависло» — это нормально, ждёт подключений.        │
│    Сюда не вводите etc/dev — сервер читает только сокет.    │
│                                                             │
│ 3. Терминал B — клиент:                                     │
│      ./client                                               │
│    Клиент сам шлёт etc и dev, ответы печатаются в этом же   │
│    терминале.                                               │
│                                                             │
│    Либо вручную через netcat:                               │
│      nc 127.0.0.1 2255                                      │
│    затем строка etc и Enter, потом dev и Enter              │
│    (именно dev, не dev/).                                   │
│                                                             │
│ 4. Остановить сервер: в терминале A — Ctrl+C                │
└─────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ ПРИМЕР ВЗАИМОДЕЙСТВИЯ:                                         │
├────────────────────────────────────────────────────────────────┤
│ Клиент → Сервер: "etc\n"                                       │
│ Сервер → Клиент: "server5239,apache2.conf,php.ini,sshd.conf\n" │
│                                                                │
│ Клиент → Сервер: "dev\n"                                       │
│ Сервер → Клиент: "disk,input,net,shm,pts\n"                    │
│                                                                │
│ Клиент → Сервер: "unknown\n"                                   │
│ Сервер → Клиент: "Unknown command\n"                           │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│ УПРАВЛЕНИЕ РЕСУРСАМИ:                                      │
├────────────────────────────────────────────────────────────┤
│ server_fd (дескриптор 3) — живёт всё время работы сервера  │
│   - создаётся один раз в socket()                          │
│   - закрывается только при завершении программы            │
│                                                            │
│ new_socket (дескриптор 4,5,6...) — создаётся для каждого   │
│   клиента в accept() и закрывается после обработки         │
│                                                            │
│ DIR *dir — открывается в build_etc_conf_list() и           │
│   build_dev_dir_list(), закрывается после обхода           │
└────────────────────────────────────────────────────────────┘
